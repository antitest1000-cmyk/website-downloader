HTML Only vs Full Page Download — Which Should You Use?

July 2025 7 min read

When you use Website Downloader, you get to choose between three distinct modes. Two of the most commonly confused are HTML Only and Single Page (Full Page) download. They sound similar, but they serve very different purposes. Let's break down exactly what each downloads, when to use each, and what the trade-offs are.

What Does "HTML Only" Actually Download?

When you select HTML Only mode, the server makes a single HTTP GET request to your target URL and returns the raw HTML response body — nothing else. The resulting ZIP will contain a single .html file.

What this file contains:

  • The full DOM structure as rendered by the server
  • All inline styles (<style> blocks)
  • All inline scripts (<script> blocks)
  • All inline SVGs and data URIs
  • References (links) to external CSS, JS, and images — but NOT the actual files

What it does not include: external stylesheets, external JavaScript files, image files, fonts, or any other linked assets.

What Does "Single Page (Full Page)" Download?

Single Page mode downloads the HTML document AND fetches all externally referenced assets:

  • All <link rel="stylesheet"> CSS files
  • All <script src="..."> JavaScript files
  • All <img src="..."> images
  • All web fonts referenced in CSS (@font-face)
  • CSS files imported via @import url(...)

After fetching all assets, the tool rewrites all absolute URLs in the HTML to relative local paths so that when you open the file offline, the browser can find every asset in the extracted folder.

When to Use HTML Only

  • SEO & technical audits — You want to inspect the raw HTML output: heading tags, meta descriptions, canonical tags, schema markup, internal link structure. CSS and images are irrelevant here.
  • Content scraping — You're extracting text data, article content, or structured data from the page. The raw HTML is all you need.
  • Speed is critical — If you need to quickly grab the markup of dozens of pages, HTML Only mode is orders of magnitude faster than Full Page.
  • Inspecting server-side rendering — You want to see exactly what the server returns before any client-side JavaScript executes.

When to Use Full Page Download

  • Offline reading — You want to read an article, documentation, or tutorial without an internet connection and see it exactly as it looks online.
  • Design inspiration — You're a designer or developer who wants to study a website's visual layout, animations, and CSS techniques offline.
  • Presentation demos — You're demonstrating a web project to a client and need a working offline copy in case the live server has issues.
  • Archiving for compliance — You need a visual record of how a page looked on a specific date for legal or regulatory purposes.

The Verdict

Use HTML Only when you're working with the code and data — it's fast, lightweight, and gives you exactly what the server sent. Use Full Page when you need the page to actually look right offline — it takes longer but delivers a complete, visually accurate copy.

How to Mirror a Static Website Step by Step

July 2025 9 min read

A website mirror is a complete, local, browsable copy of a live website. Every page, every image, every stylesheet — stored on your drive, organized the same way it is on the server. In this guide, you'll learn exactly what mirroring means, how the technology works, and how to create a full website mirror in minutes using Website Downloader.

What Is a Website Mirror?

A website mirror is a byte-for-byte replica of a website stored locally. Unlike a browser's "Save Page As" function, which typically only captures the single page you're looking at, a true mirror preserves the entire interconnected structure of the site:

  • All HTML pages
  • All CSS, JS, images, and fonts
  • The original directory structure (so relative links still work)
  • Navigational links between pages

The result is a folder on your computer where you can open index.html and browse the entire site just like you would online.

What Is Recursive Crawling?

Recursive crawling is the process a mirror tool uses to discover and download all pages. Here's how it works:

  1. Start at the given URL (e.g., https://example.com/)
  2. Download that page's HTML
  3. Parse all <a href> links on that page
  4. Filter links to keep only those on the same domain
  5. Queue unvisited links for download
  6. Repeat for every queued page until none remain

At each page, assets (CSS, JS, images) are also downloaded and saved. The crawler keeps a visited list to avoid downloading the same URL twice.

Static vs Dynamic Websites: What Can Be Mirrored?

Website mirroring works best with static sites — those that serve pre-built HTML, CSS, and JavaScript files directly from the server. Common examples include:

  • Documentation sites (e.g., built with MkDocs, Docusaurus)
  • Blogs (e.g., Jekyll, Hugo, 11ty)
  • Company brochure sites
  • Portfolios
  • Landing pages

Dynamic sites — powered by databases, user authentication, or server-side rendering per request — are much harder to mirror completely. While the HTML structure can still be downloaded, features like search, comments, login, and user-specific content will not function offline.

Step-by-Step: Mirror a Website with Website Downloader

Step 1: Verify the Site is Static

Check if the site is a static site generator. Clues include: clean URLs, fast load times, GitHub Pages or Netlify hosting, and no login system. If in doubt, try downloading a couple of pages manually first.

Step 2: Open Website Downloader

Navigate to html-get.netlify.app.

Step 3: Enter the Root URL

Paste the homepage URL into the input field. Always use the root URL — https://example.com/ rather than https://example.com/docs/getting-started. Starting at a sub-page means you'll miss everything outside that branch of the site.

Step 4: Select "Entire Website" Mode

Click the Entire Website card. This enables recursive crawling across all internal links.

Step 5: Click Start Download

Click the Start Download button. Depending on the size of the site, this may take anywhere from a few seconds (small documentation site) to several minutes (larger multi-page site).

Step 6: Extract and Browse

Once the ZIP downloads:

  1. Extract the ZIP to a folder
  2. Open index.html in your browser
  3. Navigate the site using its internal links — they all work offline

Understanding the Output Folder Structure

The extracted ZIP mirrors the site's original URL structure. For example, if the live site has:

https://example.com/
https://example.com/about/
https://example.com/blog/post-one/

The local folder will have:

index.html
about/
  index.html
blog/
  post-one/
    index.html
assets/
  style.css
  logo.png

All HTML files reference assets using relative paths, so the folder can be moved anywhere and will continue to work.

Limitations to Know

  • Login-gated content — Pages behind authentication cannot be accessed or downloaded.
  • Cloudflare / bot protection — Sites with aggressive bot protection will return 403 errors.
  • JavaScript-rendered content — Content injected by JS after page load (infinite scroll, React routing) may not be fully captured.
  • External CDN assets — Resources served from a third-party CDN (e.g., Bootstrap from a CDN) are downloaded but may not be rewritten correctly if the domain filtering is strict.

Conclusion

Mirroring a website is the most complete form of web archiving available. With Website Downloader's Entire Website mode, the complexity of recursive crawling, asset fetching, and link rewriting is handled for you — leaving you with a clean ZIP you can open and browse offline, forever.
